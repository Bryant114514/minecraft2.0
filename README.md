# minecraft2.0

复刻《Minecraft》核心玩法的最小可行版本。**100% 免费，无任何付费、内购或广告**；
所用技术栈（Vite + Three.js）均为开源免费（MIT 许可），纹理与怪物模型全部由代码实时生成，不含任何图片素材。

## 已实现功能

- **主界面 + 存档系统**：3 个存档位可随时切换游玩；每 15 秒自动存档、退出/关页自动保存；游戏内 `ESC` →「存档并返回主界面」
- 第一人称视角，鼠标锁定旋转视角
- 新建存档时可选 **生存 / 创造** 两种模式
- **背包 / 物品栏系统**：破坏方块收入背包、放置方块消耗数量；`E` 打开背包，**点击物品即可放入当前选中的快捷栏格子（背包↔快捷栏互换）**；剑/弓/箭/方块均有像素图标
- **武器系统**：
  - **剑**：近战高伤害（挥砍动画 + 攻击冷却）
  - **弓**：右键蓄力、松开射箭，蓄力越满伤害越高；箭为消耗品，骷髅会掉落箭补充
- 三种怪物，各有基础 AI：
  - **僵尸**：近战追击，靠近后攻击
  - **骷髅**：远程射箭，保持距离、太近会后退（击杀掉 2 支箭）
  - **苦力怕**：贴身开始引信（抖动闪光），随后自爆，炸掉附近方块并伤害玩家
- **地图系统**：选择模式后再选地图——「草原丘陵」或「远古城市」
- **远古城市**：深板岩地下宫殿，含幽匿块 / 幽匿感测体 / 幽匿尖啸体 / 幽匿催发体 / 强化深板岩，整体幽暗、幽匿方块会发光
- **坚守者（Warden，仅远古城市出现）**：盲眼、靠“嗅觉(近)+听觉(移动振动)”感知的首领级怪物；靠近尖啸体会召唤/激怒它；平时只用**近战重击**，**残血时才会用音爆远程攻击（无视方块，频率低）**；潜行可躲过它的听觉；击杀掉落幽匿催发体
- 生存模式：生命值、摔落伤害、死亡重生；可攻击怪物（含击退）
- 创造模式：无敌、无怪物、可飞行、物品无限
- `WASD` 移动（双击 `W` 疾跑）、`Shift` 潜行（静步，不触发尖啸/惊动坚守者）、`Space` 跳跃、`F` 切换飞行（飞行时 `Space` 上升、`Shift` 下降，与潜行同键）
- 程序化生成地形：草地、泥土、石头、树木、水池
- 快捷栏 `1-9` / 鼠标滚轮切换物品，手持物品实时显示
- 重力、跳跃与体素碰撞，不会穿墙

## 目录结构

```
Minecraft2.0/
├── package.json        # 依赖与脚本
├── index.html          # 页面 + HUD（准星/物品栏/血条/背包/蓄力条）
├── README.md           # 本文件
├── .gitignore          # 忽略 node_modules/dist
└── src/
    ├── main.js         # 入口：场景、主循环、键鼠交互、战斗/破坏、模式选择
    ├── textures.js     # 方块类型（含幽匿/深板岩）+ 程序化像素纹理
    ├── world.js        # 地图系统 + 地形生成 + InstancedMesh 方块渲染
    ├── player.js       # 玩家移动、跳跃、碰撞、生命值/模式/摔落伤害
    ├── monsters.js     # 僵尸/骷髅/苦力怕/坚守者 AI、箭矢、刷怪、爆炸与掉落
    └── inventory.js    # 物品定义、背包数据、手持武器模型
```

## 运行指南（需 Node.js 18 及以上）

```bash
# 1. 安装依赖（第一次运行需要联网下载 three 和 vite）
npm install

# 2. 启动开发服务器
npm run dev
```

终端会输出类似 `Local: http://localhost:5173/` 的地址，用浏览器打开即可。
进入主界面后点「开始游戏 / 选择存档」，选择或新建一个存档（新建需选模式 + 地图），进入后鼠标被锁定即可游玩；游戏中按 `ESC` 打开暂停菜单（可继续或返回主界面）。

> 想打包成静态站点：`npm run build`，产物在 `dist/` 目录。

## 分享 / 部署（发个网页就能玩）

本项目是纯前端静态页，**无需服务器**，两种分享方式任选：

**方式 A：单文件（最简单，直接发文件）**
```bash
npm run share
```
生成 `dist/minecraft.html`（约 490 KB 的单个 HTML，JS 已全部内联）。把它发给别人，对方**双击用浏览器打开即可玩**；也能上传到任意网盘/静态空间。

**方式 B：部署到免费静态托管（发链接）**
把 `dist/` 目录内容上传到任一免费平台即可得到公开网址：
- **Vercel / Netlify / Cloudflare Pages**：网页里拖拽上传 `dist/` 文件夹，几秒后得到 `https://xxx.vercel.app` 之类的链接。
- **GitHub Pages**：把 `dist/` 推到仓库 Pages 分支即可（已配置相对路径 `base:'./'`，子目录也能正常加载）。

> `dist/minecraft.html` 是单文件合并产物；`dist/index.html + dist/assets/` 是多文件版，二者二选一。

## 操作速查

- 视角：移动鼠标（锁定后）
- 移动：`W` `A` `S` `D` / 方向键
- 疾跑：双击 `W`（松开 `W` 停止）
- 潜行：按住 `Shift`（静步，不触发幽匿尖啸体）
- 跳跃：`Space`；飞行开关：`F`；飞行下降：`Shift`（与潜行同键）
- 攻击/破坏：鼠标左键（选中剑=挥砍攻击，选中方块/手=破坏方块）
- 射箭：选中弓后按住右键蓄力、松开射击；放置方块：选中方块后右键
- 切换物品：数字键 `1` ~ `9` 或鼠标滚轮
- 打开背包：`E`（点击物品放入当前选中的快捷栏格子）
- 选择模式/地图：新建存档时先点「生存/创造」模式，再点「草原丘陵 / 远古城市」地图
- 存档：主界面「选择存档」进入/新建/删除；游戏中 `ESC` →「存档并返回主界面」（每 15 秒自动存档）
- 释放鼠标：`ESC`

## 常见环境报错与修复

| 报错 / 现象 | 原因 | 修复命令 |
| --- | --- | --- |
| `npm: command not found` / `'npm' 不是内部或外部命令` | 未安装 Node.js | 到 https://nodejs.org 下载 LTS 版安装，重启终端后 `node -v` 验证 |
| `vite` 报错要求 Node 18+ | Node 版本过低 | 升级 Node 到 18 及以上（`node -v` 查看） |
| `npm install` 卡住或下载失败 | 网络访问 npm 官方源慢 | `npm config set registry https://registry.npmmirror.com` 后重新 `npm install` |
| `Cannot find module 'three'` | 依赖未装成功 | 重新执行 `npm install` |
| 端口 `5173` 被占用 | 端口冲突 | Vite 会自动换端口，看终端实际输出的地址即可 |
| `vite : 无法加载文件...禁止运行脚本`（PowerShell） | PowerShell 执行策略限制 | 用 `npm run dev`（走 cmd，不受影响），或 `Set-ExecutionPolicy -Scope CurrentUser RemoteSigned` |
| 打开页面黑屏 / 报 `WebGL` 错误 | 浏览器或显卡不支持 WebGL | 换 Chrome/Edge 最新版，或开启硬件加速 |
